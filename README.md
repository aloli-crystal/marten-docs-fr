# Marten - Documentation Française

Traduction communautaire non officielle de la [documentation du framework Marten](https://martenframework.com/docs/) (Crystal).

**Site** : https://aloli-crystal.github.io/marten-docs-fr/

## Contribuer

Les fichiers Markdown à traduire se trouvent dans `docs/`. La structure reprend celle de la documentation originale.

### Développement local

```bash
npm install
npm run start
```

### Build

```bash
npm run build
```

## Suivi de la documentation upstream

Un workflow GitHub Actions vérifie chaque semaine les modifications dans la documentation du [dépôt officiel Marten](https://github.com/martenframework/marten). Lorsque des changements sont détectés, une issue est automatiquement créée listant les fichiers à mettre à jour.

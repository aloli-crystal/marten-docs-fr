**Marten** est un framework web Crystal qui permet un développement pragmatique et un prototypage rapide. Il fournit un ensemble cohérent et extensible d'outils que les développeurs peuvent exploiter pour créer des applications web sans réinventer la roue.

## Prise en main

Vous découvrez le framework web Marten ? Les ressources suivantes vous aideront à démarrer :

* Le [guide d'installation](./getting-started/installation.md) vous aidera à installer Crystal et le CLI Marten
* Le [tutoriel](./getting-started/tutorial.md) vous aidera à découvrir les principales fonctionnalités du framework en créant une application web simple

## Parcourir la documentation

La documentation de Marten contient de nombreuses pages et références qui ne servent pas nécessairement le même objectif. Pour vous aider à naviguer dans cette documentation, voici un aperçu des différents types de contenu que vous pourrez rencontrer :

* Les **guides thématiques** traitent des concepts clés du framework. Ils fournissent des explications et des informations utiles sur des sujets comme les [modèles](./models-and-databases.mdx), les [handlers](./handlers-and-http.mdx) et les [templates](./templates.mdx)
* Les **pages de référence** fournissent une référence technique détaillée des API du framework
* Les **guides pratiques** expliquent comment résoudre les problèmes courants rencontrés lors de l'utilisation du framework. Ils peuvent couvrir des sujets comme les déploiements, le développement d'applications, etc.

De plus, une [référence API](https://martenframework.com/docs/api/dev/index.html) générée automatiquement est également disponible pour explorer les détails internes de Marten.

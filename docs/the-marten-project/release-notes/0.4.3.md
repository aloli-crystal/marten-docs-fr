_10 mars 2024._

## Corrections de bugs

* Garantie que les paramètres de requête sont accessibles depuis les templates.
* Correction des dossiers cachés ignorés par la commande de gestion [`collectassets`](../../development/reference/management-commands.md#collectassets).
* Correction de certains avertissements ameba dans les projets et applications générés.
* Correction de l'incohérence des définitions de la méthode `#using` entre les classes de modèle et les query sets.
* Correction des dépendances spécifiques aux bases de données manquantes dans les projets générés.

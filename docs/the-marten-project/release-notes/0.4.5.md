_5 mai 2024._

## Corrections de bugs

* Correction d'une possible erreur de compilation avec la génération d'espace de noms de paramètres personnalisés.
* Garantie que la commande de gestion [`serve`](../../development/reference/management-commands.md#serve) recompile les projets lors de modifications des fichiers de traduction.
* Correction de l'ordre des rechercheurs d'assets pour garantir que ceux associés aux répertoires d'assets configurés (via le paramètre [`assets.dirs`](../../development/reference/settings.md#dirs)) ont la priorité sur ceux associés aux répertoires d'application.

_7 février 2025._

## Corrections de bugs

* Correction d'une possible erreur de compilation pour les champs [`json`](../../models-and-databases/reference/fields.md#json) définis sans options supplémentaires.
* Correction des opérations incorrectes créées lors de la génération de [migrations](../../models-and-databases/migrations.md) pour les modèles dans lesquels plusieurs colonnes ont été renommées.
* Garantie que les chaînes traduites dans les templates (lors de l'utilisation du tag [`translate`](../../templates/reference/tags.md#translate)) sont automatiquement échappées (voir [Auto-échappement](../../templates/introduction.md#auto-escaping)).

## Corrections de bugs

* Correction du pré-chargeur de requêtes n'utilisant pas systématiquement des requêtes sans scope lors du pré-chargement des enregistrements de relation.
* Correction d'un possible problème de sensibilité à la casse lors de la spécification des noms de méthodes HTTP prises en charge par des handlers spécifiques.
* Correction d'un nom de callback incohérent dans le handler de mise à jour de mot de passe généré pour l'[application d'authentification](../../authentication/introduction.md).

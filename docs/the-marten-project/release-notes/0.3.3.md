_15 septembre 2023._

## Corrections de bugs

* Correction d'exceptions [`Marten::Template::Errors::InvalidSyntax`](pathname:///api/0.3/Marten/Template/Errors/InvalidSyntax.html) inattendues levées lors de l'ajout d'espaces entre le nom d'un [filtre de template](../../templates/introduction.md#filters) et son argument.
* Garantie que la méthode [`#add`](pathname:///api/0.3/Marten/DB/Query/ManyToManySet.html#add(*objs:M)-instance-method) des query sets many-to-many respecte l'alias de base de données ciblé.
* Garantie que les méthodes de query set [`#delete`](../../models-and-databases/reference/query-set.md#delete) et [`#update`](../../models-and-databases/reference/query-set.md#update) réinitialisent les enregistrements en cache si applicable.
* Garantie que la méthode [`#add`](pathname:///api/0.3/Marten/DB/Query/ManyToManySet.html#add(*objs:M)-instance-method) des query sets many-to-many réinitialise les enregistrements en cache si applicable.

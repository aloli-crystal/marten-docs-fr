_23 juillet 2023._

## Corrections de bugs

* Correction de possibles incohérences dans les résultats retournés par les query sets selon l'ordre des appels à [`#filter`](../../models-and-databases/reference/query-set.md#filter) et [`#exclude`](../../models-and-databases/reference/query-set.md#exclude).
* Correction de la génération incorrecte du modèle intermédiaire pour les [relations many-to-many](../../models-and-databases/introduction.md#many-to-many-relationships) récursives.
* Garantie que les méthodes `#<field>?` des modèles retournent false pour les valeurs de champs vides.
* Ajout de la méthode `#<field>?` manquante pour les champs de modèle [`file`](../../models-and-databases/reference/fields.md#file).

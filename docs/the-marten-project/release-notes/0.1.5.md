_7 janvier 2023._

## Corrections de bugs

* Correction d'un bug où certains types retournés par les champs intégrés n'étaient pas autorisés comme valeurs de template
* Correction d'un bug où il n'était pas possible de résoudre les paramètres de routage UUID à partir de chaînes UUID valides
* Garantie que les classes de modèle abstraites peuvent être créées sans champs de clé primaire
* Garantie que les sous-classes de [`Marten::Conf::Setting`](pathname:///api/0.1/Marten/Conf/Settings.html) n'ont plus besoin de définir une méthode `#initialize` obligatoire si elles n'en ont pas besoin

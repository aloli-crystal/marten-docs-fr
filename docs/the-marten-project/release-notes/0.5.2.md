_24 août 2024._

## Corrections de bugs

* Correction du nom du template texte des [emails](../../emailing.mdx) générés via le générateur [`email`](../../development/reference/generators.md#email).
* Correction d'une erreur inexistante lorsque la commande de gestion [`new`](../../development/reference/management-commands.md#new) était utilisée pour générer une structure d'application avec l'option `--with-auth`.
* Correction du dossier "emails" manquant requis dans les projets générés avec la commande de gestion [`new`](../../development/reference/management-commands.md#new).
* Correction de l'affichage des routes imbriquées lors de l'invocation de la commande de gestion [`routes`](../../development/reference/management-commands.md#routes).
* Correction de la génération d'espace de noms pour les classes de paramètres `Settings` de premier niveau.

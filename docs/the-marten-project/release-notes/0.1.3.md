_21 novembre 2022._

## Corrections de bugs

* Garantie que les callbacks avant/après suppression sont exécutés dans la même transaction que le processus de suppression
* Ajout du fichier `.gitignore` manquant dans les projets générés via la commande de gestion [`new`](../../development/reference/management-commands.md#new)
* Correction de l'hôte incorrect utilisé pour les environnements de développement lors de la génération de nouveaux projets via la commande de gestion [`new`](../../development/reference/management-commands.md#new) : désormais, les projets utilisent automatiquement l'hôte local `127.0.0.1` en développement
* Garantie que le [producteur de contexte flash](../../templates/reference/context-producers.md#flash-context-producer) prend en compte les requêtes qui n'ont pas de store flash associé afin d'éviter des exceptions `NilAssertionError` inattendues

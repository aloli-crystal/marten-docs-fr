_10 juillet 2023._

## Corrections de bugs

* Garantie que les objets de contexte fournis par les [handlers génériques](../../handlers-and-http/generic-handlers.md) sont initialisés en utilisant [`Marten::Template::Context`](pathname:///api/dev/Marten/Template/Context.html).
* Correction d'une possible erreur de compilation survenant autour de l'initialisation des variables de template.
* Garantie que les méthodes `#<field>?` des schemas retournent `false` pour les valeurs de champs vides.

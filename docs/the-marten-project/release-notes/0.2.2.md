_7 mars 2023._

## Corrections de bugs

* Correction de possibles erreurs de compilation survenant lors de l'héritage d'un schema contenant des champs avec des options
* Correction d'un problème où les validations de champs de modèle étaient incohérentes avec les callbacks de validation (par ex. les validations de champs de modèle étaient appelées avant les callbacks `before_validation`)
* Garantie que les messages d'exception et les lignes d'extraits de code sont correctement échappés dans la page de débogage des erreurs serveur
